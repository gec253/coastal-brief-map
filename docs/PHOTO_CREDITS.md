# Featured photograph credits

Private homepage preview only (`/preview/home`). These four photographs were chosen because each has a verifiable public-domain license on its own official source page, and that page identifies the subject as a place in North Carolina. No AI-generated, stock, or scraped-without-license images were used. If a source page’s license was unclear, the photograph was not used.

Captions and alt text follow the source. They do not describe a different place or subject than the source states.

Processed derivatives (AVIF/WebP at 800, 1280, and 1920 CSS pixels where the original was large enough) live in `preview/home/photos/` and are served only with the preview cookie. The public homepage does not reference them. `data/featured-photos.json` lists `src`, `alt`, `credit`, `source_url`, and `focal` so the set can be swapped or extended — including with Ed’s own photographs later.

## Rotation

The preview server picks one photograph per calendar day in America/New_York (`day-of-year modulo` the list length) so the choice is stable for the day and does not cause layout shift. `?photo=<id>` overrides the day’s pick on the private preview only, so the set can be reviewed on demand.
